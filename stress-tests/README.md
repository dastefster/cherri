# CherriCuts stress tests

Paste one file into the CherriCuts editor, tap Compile, then Export, add the shortcut in Shortcuts and run it.
Each test shows a "❌ FAIL" alert naming the action that broke and ends with "✅ ... passed" when everything is fine.
Remove an `#include` line if Compile says it is already included.

Verified on device 2026-10-16: arrays, general, notes, text-math, crypto-web.
`notes.cherri` needs a note titled exactly `Cherri Test` in the Notes app first.
